Music Theory
Notes, semitones & intervals

Western music divides the octave into 12 equal steps called semitones. If you sit at a piano and go up one key at a time (including the black keys), each step is one semitone.

We can number them 0–11, starting from C. This is called a pitch class — it tells us which note, regardless of which octave it's in.

To identify a specific note in a specific octave — like the C above middle C — we use MIDI numbers. MIDI is a standard that numbers every key on a piano from 0 to 127. Middle C is MIDI 60.

An interval is the distance between two notes, measured in semitones. The intervals are what give chords their character — a major chord sounds bright because of its major third (4 semitones). A minor chord sounds darker because of its minor third (3 semitones).

Interval Semitones Example (from C)
Minor 2nd1C → C#
Major 2nd2C → D
Minor 3rd3C → Eb
Major 3rd4C → E
Perfect 4th5C → F
Tritone6C → F#
Perfect 5th7C → G
Minor 6th8C → Ab

Building chords
in code

A chord is just a set of intervals stacked on top of a root note. We represent a chord type as an array of semitone offsets from the root. The root itself is always 0.

A major triad is built with intervals [0, 4, 7] — root, major third, perfect fifth. That's it. Three numbers fully describe the sound of a major chord, regardless of what key it's in.

Audio
Web Audio API & piano samples

Browsers have a built-in Web Audio API that lets us generate and play sound. For realistic piano sounds we use Soundfont-player, which loads pre-recorded piano samples from a public library and plays them at any pitch via the Web Audio API.

Notation
Rendering sheet music with VexFlow

VexFlow is a JavaScript library that renders music notation into SVG. We give it a list of notes (as strings like "c/4" or "f#/3") and it draws them on a staff.

The tricky part is converting MIDI numbers to VexFlow's format. VexFlow wants "noteName/octave" in lowercase, e.g. "c/4", "f#/3", "bb/5".
