HelpContent

Source: help-content.js:18

Single source of truth for all in-app Help text. Contains no DOM references or rendering logic — content only. Consumed by help-mode.js.

Data structure: HELP_SECTIONS — top-level array of section objects Each section: { id: string, title: string, entries: Entry[] } Each entry: { term: string, body: string } body is plain text; \n renders as a paragraph break.
